# Cushing-Multiome

Reproducible analysis of human adipose-tissue single-nucleus multiome data (RNA + ATAC) from Cushing syndrome and control samples.

## Repository organization

The repository contains two analysis layers:

1. **Upstream preprocessing and multiome construction** in `scripts/00_*.R` through `scripts/16_*.R`.
2. **Manuscript figure analyses** in `scripts/manuscript/`.

Large raw 10x Genomics files and large intermediate Seurat/Signac objects are not stored in GitHub.

### Upstream workflow

The existing scripts cover:

- input-file validation
- RNA quality control
- doublet detection with scDblFinder
- ATAC quality control
- SoupX ambient-RNA correction
- merging of patient objects
- union-peak construction
- common ATAC matrix generation
- RNA/ATAC Harmony integration
- WNN analysis
- broad cell-type annotation
- ASPC subclustering

### Manuscript analyses

The manuscript-level scripts reproduce:

- **Figure 1:** global adipose cell landscape
- **Figure 2:** ASPC states, disease-associated population shifts, adipogenic pseudotime, RNA pseudobulk differential expression, pathway enrichment and TF dynamics
- **Figure 3:** differential chromatin accessibility, genomic annotation, unbiased motif enrichment, motif-supported linked TF programs and the PPARG regulatory locus

See `docs/Methods_analysis.md` for the analysis methods corresponding to these scripts.

## Data

Per-sample raw inputs are expected locally and are not committed to the repository. See `data/README.md` and `config/samples.tsv` for the expected file organization.

The final manuscript analysis excludes CS4 based on the initial quality assessment.

## Reproducibility

Run the upstream scripts in numerical order. Manuscript scripts start from the finalized checkpoint objects generated by the preprocessing workflow. Intermediate RDS objects, raw HDF5 matrices, fragment files, reports and generated figures should remain local or be deposited in an appropriate data repository rather than committed to GitHub.

## Reference genome

Human GRCh38/hg38.

## Software

Core R packages include Seurat, Signac, Harmony, SoupX, scDblFinder, DESeq2, Slingshot, ChIPseeker and related Bioconductor packages.
